# Разведочный анализ данных (EDA) для проекта классификации ЭКГ на датасете PTB-XL

## 1. Изучение структуры выбранного рабочего датасета (PTB-XL)
- Число объектов (строк) и признаков (столбцов) датасета
- Типы признаков (расшифровка условных обозначений, единицы измерения, диапазон изменения / перечень принимаемых значений)
- Выделение целевых переменных в датасете, анализ распределения значений целевой переменной (диагностические метки NORM, MI, STTC, CD, HYP, …). Постановка задачи классификации
- Формулирование общих выводов по результатам изучения структуры датасета, подготовка необходимых табличных данных и визуализаций для описания структуры

## 2. Изучение особенностей данных датасета
### 2.1. Анализ метаданных
- Расчёт основных статистических метрик для вещественных и категориальных признаков (df.describe(include=’all’)): числовые – count, mean, std, min, 25-50-75%, max, категориальные – count, unique, top, freq
- Кол-во объектов в чистых классах целевой переменной (одна диагностическая метка)
- Анализ структуры многометочной классификации (общая статистика по группам с несколькими диагностическими метками)
- Оценка баланса классов в выборке, выявление редких классов
- Анализ характера связи отдельного признака с целевой переменной. Анализ наличия попарных корреляций признаков
- Визуализация попарных распределений наиболее значимых коррелирующих признаков (sns.pairplot()). Построение необходимых таблиц и диаграмм
- Наличие пропущенных значений для каждого признака (общее количество, доля от общего числа объектов). Оценка «разреженности» датасета в контектсте пропущенных значений. Поиск осмысленного и аргументированного способа обработки пропущенных значений
- Поиск ошибок в данных (выход значения признака за диапазон ожидаемых значений)
- Поиск и удаление полных дубликатов записей
- Поиск аномальных выбросов в данных. Обработка выбросов

### 2.2. Анализ ЭКГ-данных
- Поиск и визуализация примеров электрокардиограмм характерных для чистых классов (в одном масштабе времени, амплитуды сигнала, при одной частоте съёмки, в одних и тех же условиях нормализации)
- Описание характерных особенностей представленных записей (длина участков монотонного изменения сигнала, резкие скачки амплитуды сигнала, нехарактерный диапазон значений...)
- Поиск примеров записей высокого и низкого качества (по меткам шума, дрейфа базовой линии и проблем с электродами)
- Поиск и тестовое применение инструментов обработки некачественных сигналов (фильтрация шума)
